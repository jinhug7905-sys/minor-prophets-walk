# 콘텐츠 관리 규칙

사용자가 제공한 「소선지서 시간 속을 걷다 — Codex 최종 구현 마스터 명세」를 기준으로 데이터와 UI를 구성했습니다. 각 권의 내용을 보존하면서 공통 사용법을 유지합니다.

## ①~⑥

① 역사 속을 걸어보기 → ② 지금 어디에 있는가? → ③ 본문을 걸어보기 → ④ 핵심 말씀 → ⑤ 앞뒤 성경 연결하기 → ⑥ 한 장 정리.

① 파랑, ② 초록, ③ 보라, ④ 금색, ⑤ 청록, ⑥ 짙은 남색. 숫자·아이콘·제목으로도 현재 단계를 식별합니다.

## 데이터 수정

- `books.js`: `date`가 홈·랜딩·①·⑥·전체 시간표의 단일 연대 기준입니다. `flow`는 본문 범위·주제·문맥 설명을, `keys`는 핵심 범위·주제·③ 위치 인덱스·의미·문맥 읽기 범위를 담습니다. 여러 구간에 걸친 말씀이면 위치 인덱스를 배열로 지정합니다.
- `locations.js`: 지명·개략 좌표·중요성·관련 본문·불확실성 안내입니다. 같은 도시 안의 성전·시온·감람산은 라벨을 벌려 읽도록 표시합니다. 이동을 새로 추정하여 만들지 않습니다.
- `connections.js`: 역사서·다른 선지서·신약·같은 시대를 구분하며, `kind`에 직접 인용/정경적 적용/주제적 연결 등의 성격을 명시합니다.
- `deepViews.js`: 카드 유형, 제목, 설명, 읽기 본문, 노출 단계입니다. 각 권에 같은 개수의 카드를 강제하지 않습니다.
- `timeline.js`: 정거장과 관련 책을 연결합니다. 사역 범위가 겹치므로 엄격한 단일 순서로 설명하지 않습니다.
- `readings.js`: 공식 URL이 확인되기 전에는 `url: null`을 유지합니다. 검증 뒤 연결할 때에는 실제 공식 페이지의 제공처·번역·본문 범위를 확인하고 자동 테스트도 업데이트해야 합니다.

## 변경하면 안 되는 핵심 기준

- 하박국 B.C.609~605, 미가 B.C.750~680, 호세아 B.C.760~720.
- 오바댜 B.C.586 이전*·요엘 약 B.C.830~820*: 교재 기준과 연대 견해 차이를 표시합니다.
- 히브리어 직후에는 반드시 한글 발음 괄호를 둡니다. 영어 음역만 두지 않습니다. 공통 `prose` 함수는 이를 히브리어 방향·언어 표식과 한글 발음을 함께 가진 요소로 렌더링합니다.
- 아모스 8장은 “히브리어 언어유희”이며 여름 과일 → 끝 → 심판으로 읽습니다.
- 호 11:1의 출애굽 문맥과 마태의 적용을 구별합니다.
- 렘 36은 여호야김 시대 배경이며 하박국 질문의 직접 원인이나 확정된 선행 사건으로 만들지 않습니다.
- 감람산은 슥 14:4이며 슥 9:9에 직접 연결하지 않습니다.
- 말 3:1a 준비하는 사자와 3:1b 주/언약의 사자를 구별합니다. 세례 요한 적용과 예수의 정경적 연결을 구별합니다.
- 말라기의 “하나님의 아픈 마음” 등은 묵상 표현, 완악한 말에 관한 종합 표현은 학습적 종합으로 표시합니다.
- 갈그미스 B.C.609/605의 1차/2차 표기는 교재의 구분임을 유지합니다.
- 바사(페르시아) 제국 표현을 사용합니다. 말라기의 B.C.450~430 사역 범위와 B.C.444 느헤미야의 겹침을 보존합니다.
