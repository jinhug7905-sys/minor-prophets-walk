## 외부 확인이 남은 부분

대한성서공회 공식 사이트 접근에서 프록시의 `403 Forbidden`이 발생했습니다. 공식 개역개정 본문별 URL과 번역·범위를 검증하지 못했으므로 모든 읽기 카드는 “공식 링크 확인 필요”로 두었습니다. 외부 본문 읽기 동작은 통과했다고 주장하지 않습니다. 허용 도메인 설정을 적용한 뒤 실제 공식 본문 링크를 검증하여 연결해야 합니다.

지도는 개략도이며 정확한 고대 국경·특정 행군 경로를 검증한 지도는 아닙니다. 지명 비정이나 연대 논쟁은 해당 깊이 보기에서 명시합니다.
