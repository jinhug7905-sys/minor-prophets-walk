# 소선지서 시간 속을 걷다

Minor Prophets Bible History Learning App

12명의 선지자와 함께 구약 역사의 시간 속을 걷는 모바일 우선 반응형 웹앱입니다. 제공된 최종 마스터 명세를 바탕으로 정적 콘텐츠와 공통 UI를 분리했습니다.

**시대 → 장소 → 본문 → 핵심 말씀 → 앞뒤 성경 → 전체 역사**를 연결하며, 설명에서 멈추지 않고 성경 본문으로 돌아가도록 구성했습니다.

## 실행

Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다. 현재 검증 환경은 Node.js 24.19.0입니다.

```sh
cd /workspace/minor-prophets-walk
npm ci --cache /tmp/prophets-npm-cache
npm run dev
```

개발 서버 기본 포트: 5173. 일반 로컬 환경에서는 프로젝트 디렉터리에서 명령을 실행하면 됩니다. 클라우드에서 쓸 수 있는 npm 캐시 경로를 명시했습니다.

```sh
npm run build
npm test
npm run test:e2e
npm run preview -- --port 4173
```

브라우저 테스트는 `/usr/bin/chromium`을 사용합니다. 다른 경로는 `CHROMIUM_PATH`로 지정하세요. 테스트가 직접 프로덕션 미리보기 서버를 시작하고 종료합니다.

## 구현 화면

- 홈: 성경책 순서의 12권 카드, 검색, 별도의 역사 시간표 진입
- 12권별 상세 랜딩: 책 이름·연대·메시지·역사적 위치·시작하기
- ① 👣 역사 속을 걸어보기
- ② 🧭 지금 어디에 있는가?
- ③ 📖 본문을 걸어보기
- ④ 💎 핵심 말씀
- ⑤ 🔗 앞뒤 성경 연결하기
- ⑥ 🧾 한 장 정리와 전체 읽기
- 역사 시간표: 주요 정거장, 겹치는 사역 범위, 역사서 연결
- 호세아·미가 비교 화면
- 깊이 보기 / 전체 지도 / 장소 설명 / 본문 문맥 / 연결 설명 모달
- 나의 여정: 학습 완료 표시와 책별 메모의 브라우저 저장

## 콘텐츠와 외부 확인

모든 히브리어에 한글 발음을 병기합니다. 아모스 8장은 **히브리어 언어유희**로 표시합니다. 연대 논쟁, 교재 기준, 직접 인용, 정경적 적용, 주제 연결, 묵상 표현을 구분합니다.

공식 성경 URL은 검증되지 않아 **공식 링크 확인 필요** 상태입니다. 읽기 카드에 정확한 본문 범위·번역·제공처 metadata를 저장했으며 외부 URL을 임의 생성하지 않았습니다. 현재 공식 사이트 접근 시 네트워크 프록시에서 403 응답이 발생했습니다. `www.bskorea.or.kr` 접근이 허용된 환경에서 실제 본문 URL과 번역·범위를 확인한 후 연결해야 합니다. 성경 전문을 앱에 복제하지 않습니다.

지도는 개략 좌표와 지리 윤곽을 사용합니다. 정치적 국경이나 상세 이동 경로의 복원이 아닙니다. 논쟁적인 지명은 설명에 표시하고 요나 외 선지자의 가상 이동선을 만들지 않습니다.

메모·진행률은 localStorage에 저장하며 계정·서버 동기화는 제공하지 않습니다.
